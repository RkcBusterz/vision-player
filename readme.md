# Vision Player

## Installation

1. [Click here](https://github.com/RkcBusterz/vision-player/releases/download/testing/vision.player.zip) to download the latest zip (`vision player.zip`) then extract the files directly into the any folder of your choice

2. Install the required Python packages:

```bash
pip install PyQt6 python-mpv
```
*(Or `pip install -r requirements.txt`)*


## Running the Player

```bash
pythonw main.pyw
```
*(Or double-click `main.pyw` directly)*
