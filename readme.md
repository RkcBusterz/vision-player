# Vision Player

## Installation

1. Install the required Python packages:

```bash
pip install PyQt6 python-mpv
```
*(Or `pip install -r requirements.txt`)*

2. Go to **Releases** and download the latest binaries zip (`vision player.zip`), then extract the files (`mpv-2.dll`, `ffmpeg.exe`, `ffprobe.exe`) directly into the project folder.

## Running the Player

```bash
pythonw main.pyw
```
*(Or double-click `main.pyw` directly)*
